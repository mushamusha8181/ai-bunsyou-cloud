# ai-bunsyou-cloud

ブラウザで使う記事作成・編集ツール「記事ラボ」です。

## 主な機能

- DeepSeekを使った記事生成・リライト
- URLまたは貼り付け本文をソースとして利用
- 文体プロファイルの学習・保存
- Geminiによる記事内画像・サムネイル生成
- 広告素材の登録・検索・記事への挿入
- WordPressへの下書き送信
- 記事と更新履歴の保存
- IndexedDBを使った画像履歴保存
- 設定・履歴・画像をまとめたバックアップ / 復元
- API利用量からの料金目安表示

## MUSHIN Glass

ムシャムシャ系アプリ共通UI「MUSHIN Glass」`2026-10-25.2` に対応しています。

- MUSHIN / 無心フォント
- 初期キーカラー: 薄い緑 `#7FA98C`
- 初期文字色: 黒 `#000000`
- テーマ / favicon基準色: モスグリーン `#436E6A`
- ガラス濃度初期値: `72`
- フラットな情報構造 + 控えめな半透明ガラス面
- スマートフォン幅では余白と操作サイズを圧縮

「設定 → 外観と表示」からキーカラー、文字色、半透明具合を変更できます。外観設定はブラウザのLocalStorage `mushin_glass` に保存され、変更後すぐ画面へ反映されます。記事本文やプレビューなど内容そのものの色・表現は、外観テーマで不用意に上書きしません。

## データ保存

基本データと設定はブラウザのLocalStorageへ保存します。記事履歴に紐づく画像はIndexedDBへ保存します。

APIキーやWordPressパスワードはサーバー側へ保存せず、利用しているブラウザ内の設定として保持します。バックアップへ認証情報を含めるかどうかは書き出し時に選択できます。

## ファイル

- `index.html`: アプリ本体
- `mushin-icon.svg`: MUSHIN Glassアイコン
- `MUSHIN_GLASS_VERSION`: 共通UI基準バージョン

MUSHINフォントはアプリ表示に使用します。再配布条件はフォント配布元のライセンスを確認してください。
